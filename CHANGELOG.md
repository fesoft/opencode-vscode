# Changelog

## 0.1.0

- Comando para abrir o OpenCode v2 no terminal integrado.
- Comandos para modo `--standalone`, interface `mini`, continuar a última sessão e executar um prompt (`run`).
- Atalhos de teclado e item na barra de título do editor.
- Configurações: binário, argumentos extras, diretório de trabalho, reuso de terminal.
- Detecção automática da instalação e item na barra de status.
